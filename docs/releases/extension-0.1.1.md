# Seam VS Code extension 0.1.1

This extension update adds the owner-selected **Joined S** logo to the Marketplace
listing and Extensions view. It carries the same released Seam debugger 0.1.0;
the Python package on PyPI remains 0.1.0.

![Seam Joined S logo](https://raw.githubusercontent.com/ChirayuAgg0706/Seam/main/vscode/images/icon.png)

Linux x86-64 with glibc, including WSL, remains the supported platform. Requires
CPython 3.12–3.14 and LLDB with Python scripting support; prefer LLDB 19 or 20.
See the [requirements and limitations](https://github.com/ChirayuAgg0706/Seam#limitations).

Download the Linux x64 VSIX and its companion `.sha256` below. To install manually,
run **Extensions: Install from VSIX…** in a Linux or WSL window. To update the public
Marketplace listing, the owner uploads this VSIX using **Update** on the existing
`chirayuagg0706.seam-debugger` extension in the publisher management portal.

Marketplace submission and validation are separate from availability of these
GitHub release files. The first Marketplace release, 0.1.0, remains live until the
new package is uploaded and validation succeeds.
