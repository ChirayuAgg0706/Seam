# Seam extension 0.1.1

Historical release. These packages support Linux only. See the [current installation instructions](../../README.md#install) for newer packages.

This package adds the Joined S icon to the VS Code extension.
It includes the released Seam debugger 0.1.0. The Python package version is unchanged.

![Seam icon](https://raw.githubusercontent.com/ChirayuAgg0706/Seam/main/vscode/images/icon.png)

Use Linux x86-64 with glibc, including WSL, and a supported CPython interpreter.
Install LLDB with Python scripting support. Versions 19 and 20 avoid LLDB 18's
threaded-child-process failure. Read the
[requirements and limitations](https://github.com/ChirayuAgg0706/Seam#requirements).

To install this VSIX manually, run **Extensions: Install from VSIX...** in a
Linux or WSL window. This is the logo-only package. Extension 0.1.2 combines
the logo, demo GIF and revised instructions.

GitHub package availability does not confirm Marketplace publication.
The [publishing record](../publishing.md) records verified uploads.
