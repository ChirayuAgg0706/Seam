# Seam 0.1.0

Debug Python and C, C++ or Rust together on Linux x86-64, including WSL.

Seam's first public release provides one Python/native call stack, breakpoints on
both sides, and stepping into native extension code and back to Python. It supports
C API, PyO3, pybind11, nanobind and Cython modules through VS Code and Neovim/DAP.

## Install

- **VS Code:** install [Seam from Marketplace](https://marketplace.visualstudio.com/items?itemName=chirayuagg0706.seam-debugger).
  Alternatively, download `seam-debugger-chirayuagg0706-linux-x64-0.1.0.vsix` below and run
  **Extensions: Install from VSIX…**. On Windows, install in a WSL window.
- **Neovim / other DAP clients:** in a Python 3.12+ virtual environment, run
  `pip install --only-binary=:all: seam-debugger==0.1.0` from
  [PyPI](https://pypi.org/project/seam-debugger/0.1.0/). You can also download the wheel
  below and install it with `pip install /path/to/downloaded.whl`.
- Install **LLDB 19 or 20 with Python scripting support** separately; on Ubuntu 24.04,
  `sudo apt-get install -y lldb-19`. The wheel and VSIX include Seam's compiled helper.
- Run **Seam: Check This Machine** in VS Code or `seam doctor --python python3`.

[Installation and quick start](https://github.com/ChirayuAgg0706/Seam#install) ·
[Neovim configuration](https://github.com/ChirayuAgg0706/Seam/blob/v0.1.0/docs/neovim.md)

## Requirements and limits

Linux x86-64 with glibc, including WSL; CPython 3.12–3.14. Python 3.15.0rc3 was also
tested. Build your own native modules with debug information for source stepping.
Native Windows, macOS, ARM, free-threaded Python, experimental JIT and remote debugging
are outside this release's supported scope.

Python evaluation and mutation require a safe Python stop. At native stops, Python
locals/globals are read from memory with limited object inspection. Optimised code
can lose source lines and variables; child processes are not debugged. LLDB 18 has a
known threaded-child-process failure, so prefer 19/20. Restart after a crashing or
timed-out evaluated expression. See the
[complete limitations](https://github.com/ChirayuAgg0706/Seam#limitations).

## Validation

The final debugger code passed the full suite (296 passed, 16 documented skips), every
supported Python/LLDB compatibility job, real VS Code and Neovim checks, and clean
installation. Both final audit regressions passed 12 fresh packaged sessions.
[Validation details](https://github.com/ChirayuAgg0706/Seam/blob/v0.1.0/docs/v1-readiness.md).

The release assets include a manylinux stable-ABI wheel, source archive, Linux x64
VSIX and `SHA256SUMS`. Licensed under Apache-2.0.

For extension installation and registry publication, use the publisher-qualified VSIX
(`chirayuagg0706` in the filename) and its companion `.sha256`. It contains the same
debugger as the original release wheel, with the owned publisher ID and corrected
screenshot URLs. The original VSIX and `SHA256SUMS` remain available unchanged.
