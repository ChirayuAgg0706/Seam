# Seam 0.1.0

Debug Python and C, C++ or Rust in one session on Linux x86-64, including WSL.

Step Into a native function called by Python, inspect its variables, and Step Out
to Python. The call stack shows both languages in the order they ran.
Seam supports C API, PyO3, pybind11, nanobind and Cython modules in VS Code and Neovim.

## Install

For VS Code, install [Seam from the Marketplace](https://marketplace.visualstudio.com/items?itemName=chirayuagg0706.seam-debugger)
in a Linux or WSL window. The extension includes the debugger and compiled helper.
To install manually, download the publisher-qualified Linux x64 VSIX below and run
**Extensions: Install from VSIX...**.

For Neovim or another DAP client, install the package in a Python 3.12+ environment:

```bash
pip install --only-binary=:all: seam-debugger==0.1.0
```

The package comes from [PyPI](https://pypi.org/project/seam-debugger/0.1.0/).
You can also install the wheel below with `pip install /path/to/downloaded.whl`.

Install LLDB with Python scripting support separately. Use version 19 or 20.
On Ubuntu 24.04, run `sudo apt-get install -y lldb-19`.
Check the setup with **Seam: Check This Machine** in VS Code or
`seam doctor --python python3`.

[Installation and quick start](https://github.com/ChirayuAgg0706/Seam#install).
[Neovim configuration](https://github.com/ChirayuAgg0706/Seam/blob/main/docs/neovim.md).

## Requirements and limitations

Use Linux x86-64 with glibc and CPython 3.12, 3.13 or 3.14. WSL is supported.
Python 3.15.0rc3 also passed the release tests; later 3.15 builds have not been
validated for this release. Build your native modules with debug information
for source stepping.

Native Windows, macOS, ARM, free-threaded Python, experimental JIT builds and
remote debugging are outside the supported scope. At native stops, Python locals
and globals have limited inspection through memory reads. Python evaluation
and mutation need a safe Python stop.

Optimised code can lose source lines and variables. Child processes are not
debugged. LLDB 18 can lose sessions when threaded programs start children.
Versions 19 and 20 avoid that bug. Restart a session after a crashing or timed-out
evaluated expression. Read the
[full limitations](https://github.com/ChirayuAgg0706/Seam#limitations).

## Validation and files

The final debugger passed the full CI suite with 296 tests and 16 documented skips.
Python and LLDB compatibility jobs, real VS Code and Neovim checks, and clean
installation passed. Both final audit regressions passed 12 fresh packaged sessions.
The [readiness record](https://github.com/ChirayuAgg0706/Seam/blob/v0.1.0/docs/v1-readiness.md)
contains the evidence.

Assets include a manylinux stable-ABI wheel, source archive, Linux x64 VSIX
and checksums. The licence is Apache-2.0.

For extension installation, use the VSIX with `chirayuagg0706` in its filename.
Its companion `.sha256` records the checksum. It includes the same debugger as the
release wheel, with the owned publisher ID and corrected image URLs. The original
VSIX and `SHA256SUMS` remain unchanged.
