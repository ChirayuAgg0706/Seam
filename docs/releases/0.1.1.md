# Seam 0.1.1

Debug Python and C, C++ or Rust in one session.

This release adds Apple Silicon macOS support to the existing debugger. It also
fixes optimized ARM64 stack handling, native stepping, fork cleanup and breakpoint
updates during attach. Extension 0.1.3 bundles this debugger.

## Install

In VS Code, install [Seam](https://marketplace.visualstudio.com/items?itemName=chirayuagg0706.seam-debugger)
and run **Seam: Check This Machine**. For manual installation, choose the Linux x64
or macOS ARM64 VSIX below and run **Extensions: Install from VSIX...**.

For Neovim or another DAP client, create a Python 3.12+ virtual environment and run:

```sh
pip install --only-binary=:all: seam-debugger==0.1.1
seam doctor --python /path/to/project/python
```

On macOS, install Apple's command-line tools with `xcode-select --install` and use
an ARM64 Python interpreter. On Ubuntu 24.04, install `lldb-19`. LLDB is a separate
system dependency. The packages include Seam's compiled helper.

## Requirements and limits

Use Apple Silicon macOS 14+, Linux x86-64 with glibc, or Windows through WSL.
CPython 3.12, 3.13 and 3.14 are supported. Native Windows, Intel Macs, Rosetta,
Linux ARM, musl, free-threaded Python, PyPy and the experimental JIT are unsupported.

Child processes run but are not debugged. At native stops, Seam reads Python
callers from memory; Python evaluation needs a safe Python stop. Optimized code
can omit locals, source lines and native frames. Mac Step Into excludes modules
with more than 20,000 functions; use source or function breakpoints there.

Read the [installation instructions and full limitations](https://github.com/ChirayuAgg0706/Seam#readme).
Assets include two stable-ABI wheels, the source archive, two platform VSIX files,
and checksums. The first Mac release uses debugger version 0.1.1; the original
0.1.0 packages remain Linux-only.
