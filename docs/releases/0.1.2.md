# Seam 0.1.2

Debug Python and C, C++ or Rust in one session.

This documentation patch keeps the Apple Silicon debugger behavior introduced in
0.1.1. It clarifies attach permissions: Linux uses ptrace settings; macOS requires
a target that allows debugging. Protected system processes cannot be attached.
Extension 0.1.4 bundles this debugger.

## Install

Marketplace extension 0.1.4 awaits manual upload. Until then, install the Linux x64
or macOS ARM64 VSIX below with **Extensions: Install from VSIX...**.

For Neovim or another DAP client:

```sh
pip install --only-binary=:all: seam-debugger==0.1.2
seam doctor --python /path/to/project/python
```

Use Apple Silicon macOS 14+, Linux x86-64 with glibc, or Windows through WSL,
and CPython 3.12, 3.13 or 3.14. Install Apple's command-line tools on macOS with
`xcode-select --install`, or LLDB 19 on Ubuntu. Packages include the compiled helper.

Read the [installation instructions and limitations](https://github.com/ChirayuAgg0706/Seam#readme).
Mac Step Into excludes modules with more than 20,000 functions. A 15,000-function
check took about three seconds for repeated entry; source and function breakpoints
remain available in larger modules.
